# Valerie's Jobs 0.3.4-dev

- Bundled the complete neutral Spanish translation by **BRØDA TS4**, with the
  creator's permission reported by the author. Thank you for making the mod
  accessible to Spanish-speaking players!
- All 106 Spanish gameplay strings are included in the main mod package, with
  the translation's internal creator credit preserved. No separate translation
  download is necessary; installation still uses only the two usual mod files.
- Remove the old standalone Valerie's Jobs Spanish translation package when
  updating, so it does not override the bundled text in future releases.
- Original localization keys/placeholders remain unchanged. All other language
  tables retain English fallback text. No changes to interview gameplay.

English interview popups and outcome moodlet were tested in 0.3.3-dev. Spanish
keys, coverage and placeholders are validated automatically; Spanish rendering
still needs in-game confirmation. Reference game: 1.128.90.1030. Saving/reloading
an interview already in progress remains unsupported.
