# Valerie's Jobs 0.3.4

First stable release. Same gameplay as the 0.3.4-dev beta, now marked stable.

- Job applications and interviews (one-hour and two-hour), with interview
  popups and accepted/rejected outcome moodlets.
- Bundled neutral Spanish translation by **[BRØDA TS4](https://www.patreon.com/BR0DA_TS4/posts/valeries-jobs-v0-171744476)**.
  Remove any older standalone Valerie's Jobs Spanish package when updating.
- All other languages fall back to English text.

Tested on The Sims 4 1.128.90.1030. Saving and reloading while an interview is
in progress is still unsupported.
