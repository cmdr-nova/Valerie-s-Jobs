# Valerie's Jobs 0.3.5

## New: skip the next interview

Starting a new save or setting up a story? Select your Sim in Live Mode, open the cheat console (`Ctrl+Shift+C`), and enter:

```text
vj.skip_next_interview
```

Apply for a supported job normally. That Sim joins through the normal game flow without the interview, skill check, ghost listing, or interview-outcome moodlet. Normal career replacement confirmations and shift/agency selections are preserved.

- The skip is for that Sim only, not the whole household.
- It is consumed only after successfully joining a career. Canceling a picker or confirmation does not consume it.
- The following application needs an interview again unless you re-enter the cheat.
- Enter `vj.skip_next_interview false` to cancel an unused skip.
- Skips do not stack or survive restarting the game. Finish or cancel an existing interview before arming one.
- Careers that already bypass interviews, including Noble, do not consume the skip. `testingcheats true` is not required.

## Verification and installation

The user tested immediate Detective career entry with the cheat and confirmed a subsequent application required an interview, on game version `1.129.39.1030` (November 24, 2026). All 72 automated tests pass. This focused check does not certify every feature on newer EA patches; the previous full compatibility baseline remains `1.128.90.1030`. Spanish rendering still needs in-game verification.

Extract both `ValeriesJobs.package` and `ValeriesJobs.ts4script` into `Mods/ValeriesJobs`, replacing older mod files. Remove a standalone Spanish translation only if you separately installed one; Spanish is now included. Enable Custom Content and Mods and Script Mods Allowed, then restart the game.

Saving/reloading during an interview remains unsupported. Complete interviews before saving and exiting.
